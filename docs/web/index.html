These are the 12 zoo kernels from kernelport, ported from CUDA to WGSL. This page runs each port on your GPU, here in the browser, and compares every output with a reference that was itself validated against the original CUDA kernel. It uses kernelport's fixed tolerances. Nothing is uploaded anywhere.

What this checks

  1. kernelport ran each original CUDA kernel against a PyTorch reference on an NVIDIA GPU, and froze the reference only after every case matched.
  2. scripts/build_web_demo.py used kernelport's own harness to generate the inputs and the expected outputs (the frozen reference, rounded to float32). It also took the tolerances and the exact shader that kernelport verify runs.
  3. This page uploads those inputs, dispatches the WGSL shader and compares element by element. NaN and infinity positions must match, and every other value must be within atol + rtol·|expected|. For float32 that is rtol 1.3e-6 and atol 1e-5, the torch.testing defaults.

Only the float32 cases under 400 KB are included, so the page stays small. kernelport verify also runs float16 and large cases.

Check kernelport's ports on your own GPU

These GPU kernels were written in CUDA, which only runs on NVIDIA. kernelport had them ported to WebGPU, which runs on almost any GPU. This page runs every port on your GPU, right now in this tab, and checks each output against answers that were validated on the original CUDA code. Nothing is uploaded.

  1. The original CUDA kernel ran on an NVIDIA GPU and matched a reference on every test case.
  2. That reference was frozen: its expected outputs are what this page compares against.
  3. Each WebGPU port runs here on your GPU. PASS means every output matched, within fixed tolerances.

The fine print

  1. kernelport ran each original CUDA kernel against a PyTorch reference on an NVIDIA GPU, and froze the reference only after every case matched.
  2. scripts/build_web_demo.py used kernelport's own harness to generate the inputs and the expected outputs (the frozen reference, rounded to the output dtype). It also took the tolerances and the exact shader that kernelport verify runs.
  3. This page uploads those inputs, dispatches the WGSL shader and compares element by element. NaN and infinity positions must match, and every other value must be within atol + rtol·|expected|. These are the torch.testing defaults: rtol 1.3e-6 and atol 1e-5 for float32, and rtol 1e-3 (about one ulp) for float16.

Only small cases are included (up to 400 KB per float32 case), so the page stays small. float16 runs only where the GPU and browser support shader-f16. kernelport verify also runs the large cases. "time" is wall-clock time in the browser, including submission, not a kernel benchmark.
